# Portfolio Lib (abandoned)

A personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, and React Router. The project is designed to showcase a developer's profile, skills, projects, and resume in a clean and modern single-page application.

## Overview

This app acts as a digital portfolio for presenting:

- a short introduction and personal summary
- technical skills and tools
- featured projects and GitHub-based work
- resume information
- contact and navigation across sections

The interface is responsive and includes a light/dark theme, making it suitable for showcasing work in a polished, developer-friendly style.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- react-icons
- react-pdf

## Features

- Responsive portfolio layout
- Dark mode support
- Multi-page navigation for home, about, skills, projects, and resume
- GitHub projects integration via a custom hook
- Reusable card-based UI components
- Clean, modern styling for portfolio content

## Getting Started

```bash
npm install
npm run dev
```

To build the project for production:

```bash
npm run build
```
